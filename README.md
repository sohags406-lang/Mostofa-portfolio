# Mostofa Sohag — Portfolio (HTML, CSS, JavaScript)

A personal portfolio website built with plain **HTML, CSS, and JavaScript** — ready to host on **GitHub Pages**.

## 📁 Files
- `index.html` — main page (Home, About, Skills, Projects, Contact)
- `styles.css` — styling & responsive layout
- `script.js` — mobile nav, animated skill bars, contact form demo
- `profile.jpg` — profile photo

## 🚀 How to publish on GitHub Pages

1. **Create a new GitHub repository** (e.g. `mostofa-portfolio`).
2. **Upload all files** in this folder (`index.html`, `styles.css`, `script.js`, `profile.jpg`) to the repo root.
   - On GitHub: **Add file → Upload files → drag & drop → Commit changes**.
3. Go to **Settings → Pages**.
4. Under *Source*, choose **Deploy from a branch**.
5. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
6. Wait ~1 minute. Your live link will appear:
   `https://<your-username>.github.io/<repo-name>/`

## ✅ Checklist before submitting
- [ ] GitHub repo is **public**
- [ ] GitHub Pages is **enabled** and the live URL loads
- [ ] All sections visible: Home, About, Skills, Projects, Contact
- [ ] Profile image loads
- [ ] Links work on mobile and desktop

## ✏️ Customize
- Replace `profile.jpg` with any new photo (same filename).
- Edit text directly in `index.html`.
- Change colors in `styles.css` — see the `:root` block at the top.
